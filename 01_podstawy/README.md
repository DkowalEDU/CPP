**TYPY DANYCH I ZMIENNE**

**int** (Integer) - liczby całkowite, np. 5, -10.

**double lub float** - liczby zmiennoprzecinkowe (ułamki), np. 3.14. Ważne: w programowaniu używamy kropki, nie przecinka!

**char** (Character) - pojedynczy znak w apostrofach, np. 'A', '7'.

**string** - łańcuch znaków (tekst) w cudzysłowach, np. "Jan Kowalski".

**bool** (Boolean) - typ logiczny, przyjmuje tylko dwie wartości: true (prawda / 1) lub false (fałsz / 0

**Wyrażenia matematyczne i operatory**

* Dodawanie +
* Odejmowanie -
* Mnożenie * 
* Dzielenie /
* Modulo %
* Inkrementacja ++  (i=0, i++) = 0,1,2,3,4…
* Dekrementacja – (i=10, i--) = 10,9,8,7…

* += :	x += 5; (dodaje 5 do x)
* -= : 	x -= 3; (odejmuje 3 od x)
* *= : 	x *= 2; (mnoży x przez 2)
* /= : 	x /= 4; (dzieli x przez 4)
