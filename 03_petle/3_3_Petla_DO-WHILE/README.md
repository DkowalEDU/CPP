Pętla do-while to specyficzna odmiana, która najpierw wykonuje kod, a dopiero na samym końcu sprawdza warunek. 
Dzięki temu mamy gwarancję, że instrukcje w środku wykonają się przynajmniej jeden raz, nawet jeśli warunek od początku jest fałszywy.
