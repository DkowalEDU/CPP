== (Czy jest równe?): Sprawdza, czy lewa strona jest identyczna z prawą.
!= (Czy jest różne?): Wykrzyknik w programowaniu to znak zaprzeczenia.
< i > (Mniejsze / Większe)
<= i >= (Mniejsze lub równe / Większe lub równe)


Konstrukcja IF … ELSE jest jako maszyna decyzyjna. Z angielskiego IF (jeśli) i ELSE (w przeciwnym razie).

W C++ możemy stosować operatory logiczne AND OR i NOT
AND – w przypadku spełnienia wszystkich warunków wejściowych dostajemy „PRAWDE” na wyjściu
OR – w przypadku spełnienia co najmniej 1 z warunków wejściowych dostajemy „PRAWDE” na wyjściu
NOT – jest to zaprzeczenie
