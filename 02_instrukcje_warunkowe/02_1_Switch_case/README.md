**Konstrukcja switch case (instrukcja wyboru)**
* switch(zmienna) – tu podajemy to, co chcemy sprawdzić.
* case wartosc: – określa punkt startu, jeśli zmienna ma dokładnie taką wartość.
* break; – Zatrzymuje działanie bloku switch. Gdybyście o nim zapomnieli, program bez sprawdzania wykonałby kod ze wszystkich kolejnych przypadków 
* default: – odpowiednik instrukcji else. Opcja domyślna, która wykonuje się, gdy żaden z przypadków case nie pasował do zmiennej
